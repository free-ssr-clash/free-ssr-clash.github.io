一、什么是Shadowrocket？

Shadowrocket 是一款专为 iOS 平台打造的网络代理工具，功能强大且配置灵活，主要用于设置代理、实现加密流量转发，从而突破地域或网络限制，同时保障用户的上网安全与隐私。

其核心特点如下：

  • 协议支持广泛：支持 Shadowsocks、Vmess、Trojan、HTTP、HTTPS、SOCKS5 等多种协议；

  • 规则灵活：可自定义规则分流，按域名/IP/应用进行流量分类管理；

  • 流量统计详细：实时监控上传/下载速度，帮助用户精确了解网络使用情况；

  • IPv6支持完善：适配现代网络环境；

  • 兼容订阅功能：一键导入节点，动态更新配置文件，极大方便用户维护节点列表。

对于追求隐私、自由、性能的iOS用户来说，Shadowrocket几乎是必不可少的工具。

三、Shadowrocket的基础配置教程

1. 添加代理节点

Shadowrocket支持手动输入节点或通过订阅链接一键导入节点列表。推荐使用订阅链接方式，便于统一管理与自动更新。

方法一：手动添加

  • 打开Shadowrocket；

  • 点击右上角“+”图标 → 选择节点类型（如Shadowsocks、Vmess等）；

  • 填入服务器信息：地址、端口、密码、加密方式等；

  • 保存后即可看到节点出现在列表中。

方法二：使用订阅链接导入

  • 获取订阅地址（如Clash牧场或Telegram群中分享的）；

  • 打开Shadowrocket → 点击“配置” → 添加配置 → 输入订阅URL；

  • 命名后保存，并点击右上角刷新按钮同步节点。

多数节点提供商都会提供兼容Shadowrocket的专用链接。

2. 设置规则分流（可选）

Shadowrocket支持多种代理模式：

  • 全局代理：所有流量均通过代理；

  • 规则模式：按域名/IP或国家归属进行智能分流；

  • 绕过大陆地址：国内流量直连，境外流量代理。

你可以通过添加公共规则集（如ACL4SSR）来自动化管理：

  • 打开“配置”；

  • 点击“规则” → “远程规则”；

  • 添加远程规则地址（例如GitHub上的规则订阅）；

  • 启用该规则配置。

3. 启用代理

  • 配置完成后，返回主界面；

  • 点击右上角开关按钮，首次启用会提示添加VPN配置；

  • 点击“允许”，输入设备密码，授权后将自动建立VPN隧道；

  • 状态栏显示VPN图标，即表示代理已启动成功。

四、使用技巧与进阶配置

✅ 配合第三方DNS使用

推荐搭配 DoH（DNS over HTTPS）服务，如Cloudflare的 1.1.1.1，增强域名解析隐私性与准确性。

路径：设置 → DNS → 添加 → 选择 DoH → 输入地址。

✅ 绑定特定应用使用代理

可开启“分应用代理”模式，仅对部分App启用代理，如YouTube、Telegram等，节省流量并提高效率。

路径：设置 → 应用规则 → 添加 → 选择App → 指定代理方式。

✅ 实时测速与节点切换

长按某个节点可进行测速，数值越小表示连接延迟越低；推荐根据延迟情况选择速度最佳节点。

✅ 多配置切换

支持保存多个配置文件，适用于不同场景（如工作/娱乐/旅行），在主界面一键切换。

FAQ

QuantumultX 支持哪些定制化分流策略？
QuantumultX 支持域名、IP、端口、协议以及用户自定义脚本分流。结合策略组使用，可实现广告屏蔽、视频加速、游戏优化等功能，提高访问速度和个性化网络体验。
Mellow 与 Clash 的核心区别是什么？
Mellow 采用基于透明代理的架构，适合路由或系统级流量重定向，而 Clash 更偏向规则式应用代理。Mellow 的灵活性更高，但配置复杂；Clash 则兼顾易用性与功能扩展性。
Clash 如何防止规则文件冲突导致分流异常？
合理组织规则顺序，将更具体的规则放在前面，通配规则放在末尾；使用 rule-providers 分离不同来源的规则，避免重复条目，并在变更后使用日志或 debug 模式检验分流是否按预期生效。
如何优化 Clash DNS 解析速度？
可在配置文件中启用 fake-ip 模式或使用高质量的 DoH 服务（如 Cloudflare、AliDNS）。同时将 `fallback-filter.geoip` 设置为 true，避免国内域名被错误解析到境外，提高解析效率。
Netch 如何实现 UDP 游戏加速？
Netch 支持 UDP 转发，可专门为游戏流量建立高速通道。结合策略组和节点延迟检测，可有效减少丢包和延迟，提高游戏体验的流畅性和稳定性。
Surfboard 的配置文件可以与 Clash 通用吗？
Surfboard 基于 Clash 核心，因此支持大部分 YAML 配置文件，但部分字段如 rule-provider、external-controller 等可能不兼容。建议使用订阅转换工具将 Clash 文件转换为 Surfboard 兼容格式导入。
Hiddify Next 的多机场订阅如何整合？
Hiddify Next 提供合并订阅功能，可将多个链接导入同一配置，自动去重并分类节点。用户可设置优先级与标签，方便快速选择不同提供商的线路，提升连接灵活性与冗余度。
Netch 如何结合策略组实现多节点优化？
Netch 可按应用和协议设置策略组，将流量分配到最优节点。结合节点延迟检测和自动切换功能，可提高网页浏览、视频播放和游戏访问速度及稳定性。
WinXray 支持 Trojan 协议吗？
WinXray 内核基于 Xray-core，因此原生支持 Trojan 协议。用户在导入配置时，只需选择 Trojan 类型节点即可，无需额外插件，非常适合需要 TLS 伪装的环境。
Trojan 的伪装域名为何重要？
伪装域名必须是真实可访问的网站，且证书有效。它用于伪装流量，使 Trojan 的数据在外观上完全像正常 HTTPS 请求，从而有效降低被封锁和 DPI 检测的风险。
